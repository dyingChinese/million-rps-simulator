# UI 规格（UI-SPEC）

目标：一个**看起来像专业级实时仿真控制台**的中文界面，视觉冲击力强、信息密度高、1080p 下流畅 60fps。
纯原生 ESM + WebGL2 + Canvas2D，无构建步骤、无 CDN、无第三方库。所有文件在 `web/` 下。

## 1. 文件划分（web-ui 负责）

```
web/index.html            // 结构 + 内联关键 CSS + <script type="module" src="/js/app.js">
web/css/style.css         // 主题变量、布局、组件样式
web/js/app.js             // 入口：连接/控制/帧循环/状态管理
web/js/protocol.js        // 二进制帧解析（§PROTOCOL）
web/js/glview.js          // WebGL2 主舞台渲染器（双视图）
web/js/charts.js          // Canvas2D 图表组件（直方图/洛伦兹/时间序列/堆叠面积/阶层条）
web/js/panels.js          // 左参数面板 + 右数据面板 + 顶部/底部栏（DOM 构建与增量更新）
web/js/format.js          // 数字/百分比/中文单位格式化（万/亿）
web/js/mock.js            // ?mock=1 时本地合成帧（无服务器也能看界面）
```

## 2. 布局（CSS Grid）

```
┌─────────────────────────────────────────────────────────────────────┐
│ TOP BAR (56px)                                                      │
├─────────────┬───────────────────────────────────┬───────────────────┤
│ LEFT 300px  │        CENTER (flex: 1)           │ RIGHT 360px       │
│ 参数配置     │ 视图 Tab + WebGL 舞台 + 图例/HUD   │ 指标 + 图表        │
├─────────────┴───────────────────────────────────┴───────────────────┤
│ BOTTOM BAR (34px)：性能 HUD + 事件 ticker                             │
└─────────────────────────────────────────────────────────────────────┘
```
- 左/右栏独立滚动（`overflow-y:auto`，自定义细滚动条），中央舞台自适应尺寸（监听 ResizeObserver，重设 canvas 尺寸与像素比）。
- 1440×900 下中央舞台 ≥ 700×600；1280×800 仍可用。

### 顶栏
- 左：Logo 方块（CSS 绘制的 ✊✌️🖐 或 RPS 字母）+ 标题「百万猜拳演化模拟器」+ 副标题「MILLION-AGENT RPS EVOLUTION」。
- 中：预设下拉（演示 5 万 / 标准 20 万 / 百万 100 万 / 压力 200 万）+ 状态徽章（运行中/已暂停/已结束 + 回合数 + 回合/秒）。
- 右：按钮组：▶ 运行 / ⏸ 暂停 / ⏭ 单步 / ↺ 重置；速度滑条（全速 ↔ 目标回合/秒）。
- 第二行（或状态区右侧）结束条件进度条：`模式 C：回合 450 / 2000`，随帧更新。

### 左栏「参数配置」（分组可折叠）
1. 基础参数：初始人数（需重置）、初始资金、最大负债、单次猜拳成本、赌注倍率、最大年龄、人口上限。
2. 遗传繁殖：繁殖资产门槛、最小繁殖年龄、最大繁殖次数、基础生育成本、生育成本比例、基因突变率、每回合繁殖概率。
3. 匹配机制：select（随机匹配/资产相近/策略相近）+ 资产相近 ±%。
4. 结束条件：select A~E + 对应字段（阈值/百分比/回合数/连续无增长回合数）。
5. 宏观调控：4 个模式各一行 switch + 触发间隔 + 参数；每行「手动触发」小按钮；保底机制 switch。
6. 进阶模式：瘟疫 / 资源有限 / 公会 switch + 关键参数。
7. 平衡性：新手保护回合、资产软上限阈值。
- 每项：中文标签 + 数值输入（可拖拽或直接输入，紧凑）。底部固定两个按钮：「应用参数」（POST setConfig，热更新）与「重置并应用」（reset）。
- 参数控件在收到 `/api/config` 后用真实值初始化；应用后以响应 config 为准回填。

### 中央舞台
- 顶部 Tabs：「策略星系」（默认）/「财富天际线」；右侧小字图例（阶层颜色 4 个 chip；策略星系额外标注三角形三顶点：石/剪/布）。
- WebGL 画布（`glview.js`）：
  - **策略星系**：后台纹理 = `strategyGrid` 密度热图（对数色阶，冷色→亮色），叠加上层点云 `pts` 的 stratX/stratY（按 classId 着色，亮度随 wealthY、streakNorm 略增），加法混合（`gl.BLEND, ONE, ONE`）产生星云感。三角形外区域为背景渐变；可选三角边框线（CSS/SVG 叠加或第二 draw call）。
  - **财富天际线**：x=laneX、y=wealthY 的点云（颜色按阶层；加法混合），叠加水平网格线与直方图轮廓（Canvas2D 或 WebGL line strip），形成"百万人的财富轮廓"。
  - 点尺寸：`gl_PointSize` 随 devicePixelRatio 与视图缩放；用圆形软边点（fragment 里 `smoothstep` 去掉方形边缘）。
  - 交互：滚轮缩放（0.5x~8x）、拖拽平移、双击复位；点击 → 在屏幕空间找最近采样点（读缓存 positions 数组），发送 `track` 指令并在右栏显示追踪卡。
  - 画布左上悬浮 HUD：回合、存活人口、总资产、基尼；右上：渲染 FPS、采样点数。
- 底部图例/提示条：如「点击任意个体追踪其一生 · 滚轮缩放 · 拖拽平移」。

### 右栏（自上而下）
1. KPI 卡片 2×3：存活人口、总资产、平均资产、近似基尼系数、当前单次成本（通胀）、平均策略熵。
2. 「出拳使用率」三色横条（石/剪/布，本回合实际占比）。
3. 资产分布直方图（Canvas，128 箱，带中位数/P90 竖线标注）。
4. 洛伦兹曲线（Canvas，显示基尼数值与 45° 参考线）。
5. 人口 / 总资产时间序列（Canvas 双轴折线，可切换指标：人口、总资产、出生/死亡、基尼）。
6. 策略演化堆叠面积图（石/剪/布主导占比，Canvas）。
7. 阶层结构：水平堆叠条（4 阶层人数占比 + 各阶层资产占比双条），下方 4 行明细（人数、占比、资产占比）
   + **阶层流动 chips（上移/下移/流动率）与每阶层「流入 X · 流出 Y」**（第 2 轮新增）。
8. 家族排行表：Tabs「资产 Top10」/「人数 Top10」，列：排名、家族、资产、人数、代数。
9. **公会排行表（第 2 轮新增）**：Tabs「资产 / 人数 / 胜场」，列：排名、公会、等级 Lv（彩色 chip）、人数、金库、总资产、胜场；
   摘要行（公会数 / 平均等级 / 金库总额 / 团体战次数）；公会模式关闭时显示「未开启（在参数面板开启公会模式）」占位。
10. 事件流：最近事件列表（时间/回合、类型标签、标题、影响金额±），新事件从顶部滑入高亮。
11. 追踪个体：每张卡显示 #ID、资产、年龄、阶层、天赋、策略三项、胜/负/平、繁殖次数；迷你资产曲线 sparkline；「取消追踪」按钮。最多 8 个。

### 底部栏
- 左：连接状态圆点（已连接/断开重连中）+ 文本。
- 中：性能 HUD：回合/秒 · tick ms · 分析 ms · 帧大小 KB · 采样点 · 渲染 FPS · JS 堆 MB。
- 右：结束条件/结束原因；暂停时显示「已暂停」。

## 3. 视觉规范（深色科技风）

```css
--bg-0:#080b12; --bg-1:#0e1420; --bg-2:#141c2b; --panel:#121a28; --panel-2:#172234;
--line:#22304a; --line-soft:#1a2536;
--text:#e8eef9; --text-dim:#8fa3bf; --text-faint:#5f7391;
--accent:#54d3ff; --accent-2:#7c5cff; --good:#42d392; --warn:#f5b942; --bad:#ff5d73;
```
- 字体：`"Segoe UI", "Microsoft YaHei UI", "PingFang SC", system-ui, sans-serif`；数字用 `ui-monospace, "Cascadia Mono", Consolas, monospace`（`font-variant-numeric: tabular-nums`）。
- 面板：`background: linear-gradient(180deg, rgba(23,34,52,.92), rgba(14,20,32,.92))`，`border:1px solid var(--line)`，`border-radius:12px`，轻微内阴影。
- 标题用小号大写英文 + 中文（如 `策略星系 STRATEGY GALAXY`），字距 0.08em，颜色 --text-dim。
- 主按钮：accent 渐变；危险操作用红色描边。悬停/按下有过渡（120ms）。
- 不要滥用发光/动画；数值变化用 300ms 过渡仅限 KPI 卡片。
- 背景可加极淡径向渐变与 1px 网格纹理（CSS），不要抢视觉。

## 4. 数据与刷新策略

- 连接 `/api/stream`，`fetch` 读取流并按 §PROTOCOL §2 解析帧；断线后 1s 退避重连（指数退避上限 8s），重连后继续。
- 单帧处理：解析 JSON + 建立 TypedArray 视图（零拷贝）→ 更新 WebGL 缓冲 → 更新 DOM/图表。**所有 DOM 更新节流到 ≥ 80ms**（用 rAF + 时间戳），图表在 rAF 中统一重绘。
- DOM 采用预创建 + 增量更新；表格/事件列表用行池复用，避免 innerHTML 反复重建。
- 数字格式化：<1 万显示原值（最多 1 位小数）；≥1 万 `x.xx 万`；≥1 亿 `x.xx 亿`；负资产红色显示。
- 错误处理：`/api/config` 失败或流断开时显示顶部提示条，不崩溃；mock 模式（`?mock=1`）无需服务器即可渲染全部面板（用 `mock.js` 生成与真实 schema 一致的数据，最好带缓慢演化的假数据以便观察动画）。
- 提供 `?mock=1` 与 `?mock=1&delay=3000`（首次帧延迟）调试参数。

## 5. 验收标准

1. `node scripts/serve-web.js` 启动静态服务后，浏览器打开 `http://127.0.0.1:8090/?mock=1` 无 console 报错，布局完整（用 Edge 无头截图验证：见 §6）。
2. 真实服务器（`npm start`）启动后，浏览器连接流，所有面板随数据更新，无内存泄漏迹象（帧解析缓存复用）。
3. 帧解析函数对「未知 section / 缺字段」健壮；magic 错误时跳过该帧。
4. 至少 WebGL 与 Canvas 图表各自在 60fps 刷新下无明显卡顿；DOM 更新无 layout thrash（用 `requestAnimationFrame` 合批）。
5. 代码中文注释清晰，无第三方依赖，无构建步骤。

## 6. 自检方式（无浏览器环境）

> 本项目的开发/验收环境为受限 Windows 沙箱，**无法启动浏览器**（Edge 内部 mojo IPC 被沙箱拒绝，
> `--headless=new --screenshot` 无法出图）。因此视觉验收改为三层可执行自检 + 网页内自检：

```powershell
# 1) Node 端 DOM/Canvas2D/WebGL2 桩：完整执行 web/js 全部模块（mock 模式 30+ 帧）
node test/web-stub.test.js

# 2) 页面内自检（浏览器打开，右上角显示绿色「自检通过 21 项」）
#    http://127.0.0.1:8080/?selftest=1      ；纯前端 mock 模式：http://127.0.0.1:8080/?mock=1

# 3) 静态服务（可选，独立于模拟后端）
node scripts/serve-web.js   # → http://127.0.0.1:8090/?mock=1
```

人工视觉最终确认：在带浏览器的机器上打开真实服务端地址（`node src/index.js` 后访问 `http://127.0.0.1:8080/`），
检查 WebGL 双视图、右栏图表、参数面板与追踪交互的观感。自检报告见 `artifacts/ui-selfcheck.md`。
